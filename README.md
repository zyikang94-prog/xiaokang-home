# 小康之家・Xiaokang Home

> 一个运行在本地、面向家庭的财产管理应用：记录收入、支出、资产与负债，自动计算净资产、各部分收益率与历年资产趋势。数据完全保存在本地浏览器，
>
> **无需注册、不依赖云端、不上传任何账目数据**
>
> 。



***

## 功能特性

### 家庭总览



* 净资产、总资产、总负债、整体收益率一览；

* 本年收入、支出与结余；

* 资产构成环形图（固定资产 / 银行存款 / 移动现金 / 股票 / ETF / 贵金属）；

* 现金资产卡片：移动现金、银行存款、股票、ETF 四项金额与占比；

* 历年资产趋势：总资产、净资产、现金资产三条曲线（每月自动记录）；

* 近 12 个月收支趋势、最近记录。

### 家庭收入



* 按月记录，支持工资、奖金、理财收益、兼职、公积金、报销、其他等来源；

* 全年各月柱状图、各年收入对比；

* 可查看月金额、年收入、月均（年化）、最高单月与跨年累计。

### 家庭支出



* 三大类：固定支出、生活支出、额外支出；

* 各月堆叠图，鼠标悬停显示当月三类明细与「支出总额」；

* 三类支出占比环形图，支持按年查看。

### 资产负债



* **固定资产**：房产、汽车（购置成本 vs 当前估值）；

* **现金资产**：移动现金、银行存款（本金 vs 余额，可记年利率）；

* **股票 / ETF**：份额、每股成本、当前价、市值、收益、收益率，支持一键刷新行情；

* **贵金属**：黄金、白银、铂金等，按克数与每克成本计价，黄金支持一键刷新金价；

* **负债**：房贷、车贷、信用卡、消费贷、其他，可记月供；

* 自动计算总资产、净资产与整体收益率。

### 数据备份



* 一键导出全部数据为 JSON，随时导入恢复。

## 快速开始

### 环境要求



* Node.js **18 及以上**（推荐 20 LTS）；

* npm（随 Node 一起安装）。

### 安装与启动



```
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

启动后访问终端中显示的地址（本项目固定端口为 **27153**：[http://localhost:27153/](http://localhost:27153/)）。

### macOS 一键启动

双击项目根目录下的 `启动小康之家.command`：



* 自动检测依赖，首次运行自动安装；

* 启动服务并打开浏览器；

* 若服务已在运行，双击直接打开页面。

### 构建与检查



```
npm run build   # 构建生产版本，产物输出到 dist/
npm run lint    # 类型检查 + ESLint
```

## 使用指南

### 录入收入

进入「家庭收入」→「记一笔」，选择日期、金额、来源即可；顶部可切换年份查看不同年度。

### 录入支出

进入「家庭支出」→「记一笔」，选择大类（固定 / 生活 / 额外）、子分类与金额；鼠标悬停月度图中任意月份，可查看该月三类明细与支出总额。

### 登记资产

进入「资产负债」，通过顶部 Tab 切换：



* 现金资产：添加股票、ETF、移动现金、银行存款；

* 贵金属：添加黄金等；

* 固定资产：添加房产、汽车；

* 负债：添加各项负债。

### 一键刷新行情



* 股票 / ETF：在「现金资产」Tab 点「一键刷新行情」；

* 黄金：在「贵金属」Tab 点「一键刷新金价」；

* 均需联网；代码填写 6 位数字即可，系统自动识别沪市（sh）/ 深市（sz）。

### 收益率口径



* 采用**简单总收益**口径：`收益率 =（当前市值 − 投入成本）/ 投入成本`；

* 股票 / ETF：成本 = 每股成本 × 份额，市值 = 现价 × 份额；

* 贵金属：成本 = 每克成本 × 克数，市值 = 当前每克价 × 克数；

* 整体收益率 = 全部资产增值 / 全部投入成本。

## 数据存储与隐私



* 所有数据保存在**当前浏览器的 localStorage**（命名空间 `xiaokang-home`），不会上传到任何服务器；

* 换电脑、换浏览器、重装系统或清理浏览器缓存，数据不共享或会丢失；

* **建议定期**用侧栏左下角「数据备份」导出 JSON 存档，换设备后导入即可恢复；

* 行情刷新仅在点击时向公开行情服务请求价格，不发送你的任何账目数据。

## 常见问题

**Q：换了电脑还能看到数据吗？**

A：数据存在原浏览器，不会自动同步。在旧设备「数据备份」导出 JSON，在新设备导入即可恢复。

**Q：一键刷新没有反应 / 提示失败？**

A：请检查网络连接，确认股票代码为 6 位数字。行情来自公开服务，非交易时段可能返回上一收盘价。

**Q：白银、铂金怎么刷新？**

A：目前仅黄金支持一键获取国内金价，白银 / 铂金请在编辑中手动填写当前价。

**Q：数据安全吗？**

A：数据只保存在本机浏览器，不经过任何服务器；但仍建议定期导出备份，防止清理缓存导致丢失。
